# World Population Trend and CO2 Emission Analysis

### MSc in Big Data Analytics — AUCA

This project analyzes world population trends and CO2 emissions using R. The aim is to explore population changes, compare countries, and examine the relationship between population and CO2 emissions.

## View the Assignment

**[View HTML Report](https://umutoni123.github.io/Population-CO2-Analysis/)**

## Dataset

The project uses two datasets from Kaggle:

- World Population Dataset
- CO2 Emission Dataset

## Analysis

The analysis includes:

- Data cleaning and exploratory data analysis
- Population prediction for 2030
- Population trends from 1990 to 2022
- CO2 emissions per capita
- Correlation analysis and visualizations
- Comparison of CO2 emissions across continents

## Tools Used

- R
- RStudio
- Quarto
- ggplot2
